# 部分集合の列挙

## s の部分集合を全部回す

```cpp
for(int t = s; t > 0; t = (t - 1) & s) {
   // t は s の部分集合。s から降順。空集合は来ない
}
```

空集合も欲しいときは、最後に判定する形にする。

```cpp
for(int t = s;; t = (t - 1) & s) {
   // ここで t を使う。t = 0 も来る
   if(t == 0) break;
}
```

`t = 0` のときに `(t - 1) & s == s` に戻るので、`t > 0`
を条件に置くと無限ループしない代わりに空集合が落ちる。
どちらが要るかで形を変える。

真部分集合だけなら `t = (s - 1) & s` から始める。

## 全体で 3^n

```cpp
rep(s, 1 << n) for(int t = s; t > 0; t = (t - 1) & s) {
   // ...
}
```

各要素は「s に入らない / s と t の両方に入る / s だけに
入る」の3通りなので、組み合わせは 3^n。n = 18 で 3.9e8、
n = 20 で 3.5e9。

## 余りの側

`s ^ t` が「s のうち t に入らない部分」。2つに分ける DP は
`dp[s] = min(dp[t] + f[s ^ t])` の形で書く。
`t` が全部回るので `s ^ t` も全部回り、片側だけ回せばよい。
