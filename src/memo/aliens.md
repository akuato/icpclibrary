# Aliens（λ の二分探索）

「**ちょうど k 個使う**」という制約を、ペナルティ `λ` に置き換
えて外す。外した方は普通に解けるようになる。

## 使える条件

```
1. 「ちょうど k 個」の制約があり、外せば解ける
2. F(k)（ちょうど k 個のときの最適値）が凸
3. λ を動かすと選ばれる個数が単調に動く（2 から自動的に出る）
```

「k 個以下」なら `λ >= 0` に制限するだけで凸は要らない。
**「ちょうど」のときだけ凸が必須**。

## 最小化と最大化

| | 最小化 | 最大化 |
| --- | --- | --- |
| 必要な凸性 | 差分が広義単調増加 | 差分が広義単調減少 |
| 目的 | `F(k) + λk` を最小化 | `F(k) - λk` を最大化 |
| 最後の戻し | `G(λ) - λk` | `G(λ) + λk` |

目的でやったことの逆を最後にやる。`λ` を増やすと個数が減る、
という向きはどちらも同じ。

## ライブラリ

```cpp
// 「ちょうど k 個」の制約を λ に置き換えて外す
//
// 使える条件（1 を破ると黙って違う値を返す）
//   1. F(k) が凸
//        最小化 -> 差分 F(k+1)-F(k) が広義単調増加
//        最大化 -> 差分が広義単調減少
//        全域木・森なら保証。DP なら小さいケースで実験して確かめる
//   2. f の中で λ を 最小化なら足す / 最大化なら引く
//   3. 同点のとき個数が最大になる側にタイブレークする
//        これを忘れると「ちょうど k」が作れない
//   4. [lo, hi] は十分広く。1 回の値域が C なら [-C-1, C+1]
//   5. 呼ぶ前に両端で k が達成可能か確かめる
//        f(lo).second < k か f(hi).second > k なら -1
//
// 対応していないもの
//   凸でない / λ が整数で足りない（実数コスト）/ 構成を出す
//   / オーバーフロー
//
// 同じ傾きが並ぶ（平坦部）のは対応済み。その区間の k は
// 全部同じ直線に乗るので F(k) = G(λ) - λk がそのまま成り立つ
//
// f(lam) -> {最適値, 使った個数}
// 返り値: ちょうど k 個のときの最適値
template<class F> ll aliens(ll lo, ll hi, ll k, bool mx, F f) {
   ll best = lo;
   while(lo <= hi) {
      ll mid = lo + (hi - lo) / 2;
      if(f(mid).second >= k) best = mid, lo = mid + 1;
      else hi = mid - 1;
   }
   auto [v, c] = f(best);
   return mx ? v + best * k : v - best * k;
}
```

## f を書くときに守ること

```
- 同点のとき個数が最大になるようタイブレークする。
  これを忘れると「ちょうど k」が作れない
- λ の範囲はコストの最大値で挟む。1 回の値域が C なら
  [-C-1, C+1]
- 呼ぶ前に、両端で k が達成可能か確かめる。
  f(lo).second < k か f(hi).second > k なら -1
- 二分探索の中は毎回ソートし直さない。λ は片方の群を
  平行移動させるだけなので、2 群を 1 回ずつソートして
  マージする
```

## 凸かどうかの確かめ方

マトロイド（全域木・森）なら保証される。DP のときは実験。

```cpp
// 小さいケースで F(k) を全探索して、差分の単調性を見る
for(int k = 0; k + 2 <= K; k++)
   assert(F[k+1] - F[k] <= F[k+2] - F[k+1]);  // 最小化
```
