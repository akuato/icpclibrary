# バックスラッシュが打てないとき

`¥` (U+00A5) はコンパイルエラーになる。見た目が近いので
気づきにくい。開始直後に `\n` を打って確認する。

## 直す

- `Option + ¥`
- 入力ソースを ABC（英字）にする
- システム設定 → キーボード → 入力ソースの「編集」→
  日本語 →「"¥" キーで入力する文字」を `\` にする
- それでも `¥` なら配列の誤認。システム設定 → キーボード
  →「キーボードの種類を変更」で再判定する
- US 配列の `\` は `]` の右隣。JIS だとその位置は `[`

## 打てないまま書く

`\` を1文字も使わずに通せる。改行はこれで済む。

```cpp
cout << x << endl;      // flush が入るので遅い
const char nl = 10;     // '\n' と同じ
cout << x << nl;
putchar(10);
```

タブや二重引用符の中の改行が要るときも、`char` の数値で
置ける。`"a\nb"` は `string("a") + char(10) + "b"`。
